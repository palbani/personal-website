# Paul Albani - Personal Resume Website

A modern, responsive personal resume website built with HTML, CSS, and JavaScript. This website showcases professional experience, skills, education, and contact information in a clean, professional design.

## Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Modern UI**: Clean, professional design with smooth animations and transitions
- **Interactive Navigation**: Smooth scrolling and active section highlighting
- **Easy to Customize**: Simple HTML/CSS/JS structure for easy updates
- **Free Hosting**: Can be hosted for free on GitHub Pages
- **No Dependencies**: Pure HTML, CSS, and JavaScript - no frameworks required

## Quick Start

### View Locally

1. Clone this repository
2. Open `index.html` in your web browser
3. That's it! No build process or dependencies required.

### Host on GitHub Pages (FREE)

Follow these steps to host your website for free on GitHub Pages:

1. **Push to GitHub**:
   ```bash
   git add .
   git commit -m "Initial commit: Personal resume website"
   git push -u origin main
   ```

2. **Enable GitHub Pages**:
   - Go to your GitHub repository
   - Click on "Settings" tab
   - Scroll down to "Pages" section in the left sidebar
   - Under "Source", select the branch you want to deploy (usually `main`)
   - Select the root folder `/` (or `/docs` if you moved files there)
   - Click "Save"

3. **Access Your Website**:
   - Your site will be published at: `https://[your-username].github.io/[repository-name]/`
   - For example: `https://paulalbani.github.io/personal-website/`
   - It may take a few minutes for the site to go live

4. **Custom Domain (Optional)**:
   - If you own a custom domain, you can configure it in the GitHub Pages settings
   - Add a CNAME file with your domain name
   - Configure DNS settings with your domain provider
